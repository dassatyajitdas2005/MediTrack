# Student Attendance — OpenCode Instructions

## Project Type
This is a frontend web application built with HTML, CSS, and JavaScript, with Firebase integration/rules.

## Important
- Do NOT treat this as a Python, Ballerina, or Streamlit project.
- Preserve the existing HTML/CSS/JavaScript architecture unless explicitly asked to change it.
- Do not rewrite the whole project unnecessarily.
- Before modifying code, inspect the relevant existing files and understand their current structure.
- Make focused changes only for the requested task.
- Do not modify Firebase configuration or security rules unless explicitly requested.

## Development Rules
- Keep the UI responsive for desktop, tablet, and mobile.
- Reuse existing styles and components where possible.
- Do not remove existing functionality without permission.
- Explain what will be changed before making large or structural changes.
- For risky or destructive operations, ask for confirmation first.

## Testing
After changes, verify the affected HTML/JavaScript functionality in the browser and check for console errors.
