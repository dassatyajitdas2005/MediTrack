# 🏥 MediTrack
### Hospital Internship & Training Management System

## 📖 About

**MediTrack** is a modern Hospital Internship & Training Management System developed to simplify the management of interns, doctor schedules, attendance, and training progress.

The application supports multiple user roles such as **Admin**, **Student/Intern**, and **Supervisor** with role-based access control.

This project is built using modern web technologies and is designed to be responsive, user-friendly, and scalable.
